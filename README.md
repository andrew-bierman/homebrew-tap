# homebrew-tap

Homebrew formulae and casks for andrew-bierman projects.

```sh
brew tap andrew-bierman/tap
brew install andrew-bierman/tap/lambe
```

| Name | Kind | What it is |
| --- | --- | --- |
| `lambe` | formula | Symphony-style supervisor for coding agents ([andrew-bierman/lambe](https://github.com/andrew-bierman/lambe)). Updated by its release workflow. |
| `fantasma` | cask | See its cask file. |
